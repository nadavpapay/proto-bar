# Where this goes

The shop admin is its own section of the dashboard, under `/admin`. Before the first screen:

1. Add the three routes (`/admin`, `/admin/orders`, `/admin/orders/:id`) behind the staff sign-in.
2. Use the product's own card, pill and button. The demo's `ui.tsx` shows the look they need, not code to copy.
3. Format money with the product's existing helper.
